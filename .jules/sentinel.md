## 2024-03-12 - Prevent Command Argument Injection in Beets Call
**Vulnerability:** In `src/services/tagging.py`, the `_pass_1_beets` function was vulnerable to command argument injection because it directly interpolated user-controlled file paths into an external command executed via `subprocess.run` (`[beet_bin, "import", "-q", "-C", "-s", str(file_path)]`).
**Learning:** External processes (like `beet`) often parse arguments sequentially. If a user-supplied file path begins with a hyphen (e.g., `-rf`, `--config`), the executable will misinterpret it as a command-line flag rather than a positional file path argument, potentially leading to arbitrary command manipulation or argument injection attacks.
**Prevention:** Always use the `--` double-dash separator to explicitly signal the end of command options. Ensure that any dynamic or user-controlled strings (like file paths) are appended *after* `--` in the arguments list when calling external commands via `subprocess.run`.
