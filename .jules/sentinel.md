## 2024-03-26 - PocketBase Filter Injection via Incomplete String Escaping
**Vulnerability:** PocketBase filter parameters constructed via string formatting `f"file_path='{file_path_str}'"` were vulnerable to filter injection if the input string was only partially escaped (e.g., `replace("'", "\\'")` instead of also escaping backslashes first).
**Learning:** Manual single quote escaping is insufficient. Because the Python SDK lacks the JS SDK's `pb.filter()` parameter binding, developers must write defensive utility functions. An attacker could supply an input ending in `\'` which, when single quotes are replaced, becomes `\\'`, effectively tricking the parser into treating the backslash as escaped and leaving the single quote unescaped, leading to query injection or server errors.
**Prevention:** Always use the custom `sanitize_pb_filter` utility function from `src.core.security` to construct safe filter strings. This utility correctly escapes backslashes first, then single quotes.
