## 2024-05-18 - Prevent Command Injection via Beets CLI Call
**Vulnerability:** A command injection risk existed in `src/services/tagging.py` (`_pass_1_beets`) where an untrusted file path string (`str(file_path)`) was passed directly to `subprocess.run(["beet", "import", "-q", "-C", "-s", str(file_path)])`. If a file name began with a hyphen (e.g., `-rf_file`), the CLI tool (`beet`) would misinterpret the path as command-line arguments, potentially causing unintended side effects or failures.
**Learning:** Command line utilities often interpret positional arguments beginning with `-` as options or flags unless explicitly told otherwise. Directly passing user-controlled or dynamically generated file names without a separator introduces command injection risks specific to argument parsing.
**Prevention:** Always insert the `--` delimiter before any positional arguments containing arbitrary paths when invoking external commands via `subprocess.run` (e.g., `["beet", "import", "-s", "--", path]`). The `--` signals the end of command options, forcing the utility to treat subsequent strings strictly as positional arguments.
